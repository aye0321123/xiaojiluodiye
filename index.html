02 / Features

AI驱动的
营销增长引擎

01

Smart Tracking

智能行为追踪

自动收集按钮名称、目标链接、页面URL、浏览器信息、屏幕尺寸。优先识别UTM参数，再分析referrer域名，最后判断直接访问。异步上报Supabase，零阻塞。

→
02

Data Dashboard

实时数据仪表板

总点击、今日点击、热门按钮排行、运营人员分析、联系方式转化率，趋势图+饼图+环形图+数据表格，支持日期范围和运营人员多维筛选。

→
03

CMS Engine

内容管理引擎

数据与视图完全分离，localStorage存储内容。左侧菜单+右侧编辑区，修改文字、图片、链接后实时同步到官网，支持数据导出和一键重置。

→
04

Multi-Platform

全端覆盖

移动端落地页（荧光绿+青蓝科技风）、PC官网（动态渲染+宽屏布局）、管理后台、运营系统。根据域名自动跳转对应版本。

→
05

Motion System

动效体系

滚动淡入动画、鼠标视差跟随、脉冲按钮+水波纹点击、渐变色流动文字、数字滚动计数器。毛玻璃+渐变+阴影+圆角，全套设计系统。

→
06

Auto Deploy

自动化部署

腾讯云COS一键上传全部文件，GitHub Actions自动部署Pages。彩色日志输出、错误处理、域名智能跳转，开发环境自动免跳转。
